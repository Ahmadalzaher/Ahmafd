## Mobile gate app (PWA) — added after this handover was first written
- New plugin `akf-gate-app`, installable web app at `https://arab-kulturfestival.de/akf-scan/`.
- Staff sign in with WordPress credentials / Application Password; the server returns a 64-hex session token stored only as SHA-256, valid 8 hours. No token appears in audit logs.
- API namespace `akf/v1/app`: `login`, `me`, `gates`, `validate`, `checkin`, `undo`. Every call resolves the token, checks the user's `akf_scan` / `akf_undo_checkin` capability and delegates admission to the core `AKF_REST` atomic check-in.
- Strict offline policy: the UI disables Check/Undo when offline, and the service worker never caches `/wp-json/` responses.
- Manifest + service worker served at `/akf-scan/manifest.json` and `/akf-scan/sw.js`. Icons are generated locally in the plugin assets.
- Verified live: login 200, `me` 200, `gates` 200 (gate #1 `Haupteingang`), `validate` → valid, `checkin` → admitted, second `checkin` → `already_used`. Test ticket `AKF-2026-000002` was cancelled afterwards.
- Release file: `yalla-events/release/akf-gate-app-1.0.0.zip`.

## Admin workflows
- **Manual invitation:** Yalla Engage → AKF Tickets → select event/type, guest, persons → Issue invitation. PDF is attached to the email; raw token is never displayed again.
- **Cancel invitation:** same page → Cancel in the ticket row (audit entry is kept).
- **Gate scan:** Yalla Engage → Gate Scanner → Start camera or paste token → Check ticket. Offline state disables admission. Undo requires supervisor capability and a reason.
