# تقرير تسجيل الحضور الذاتي + QR الخاص بالموظفين

## 1) البنية الحالية التي فُحصت قبل التنفيذ
- `yena_registrations` يمنع تكرار البريد لنفس الفعالية، لكنه لا ينشئ تذاكر بوابة.
- `akf_tickets` هو مصدر الحقيقة للماسح؛ التذاكر تُنشأ عبر `AKF_Tickets::issue()`.
- `AKF_PDF::generate()` يستخدم التصميم المعتمد دون تعديل.
- لم يكن يوجد تدفق تحقق بريد إلكتروني.

## 2) التغييرات المنفذة
### قاعدة البيانات (ترقية غير مدمرة، `AKF_DB_VERSION` 1.0.4)
- `akf_selfreg_events`: إعدادات الفعالية + رمز QR فريد + حالة (Active/Disabled/Expired).
- `akf_selfreg`: تسجيلات + رمز تحقق مشفر + انتهاء صلاحية + ticket_id.
- إصلاح عام: `AKF_Ticket_Types::save_type` و`AKF_Events::save` يملآن المفاتيح الفريدة الموجودة في قاعدة البيانات الحية (`type_key` / `event_key`).

### REST API جديدة (كلها تحت `akf/v1/reg`)
| Endpoint | Method | الغرض |
|---|---|---|
| `/event?token=` | GET | بيانات فعالية عامة (بدون PII) |
| `/start` | POST | إنشاء تسجيل معلّق + بريد تحقق |
| `/verify?code=` | GET | تحقق لمرة واحدة + إنشاء تذكرة + PDF + بريد |
| `/resend` | POST | إعادة إرسال التحقق (معدّد) |
| `/staff/qr` | POST | QR تسجيل للموظف، يتحقق من صلاحية الفعالية |
| `/admin/config` | POST | إعدادات الفعالية (أدمن) |
| `/admin/list` | GET | التسجيلات (أدمن) |

### صفحات
- عامة: `/akf-register/?token=...` — DE/EN/AR، فورم، موافقة خصوصية.
- أدمن: Yalla Engage → **Self-Service Registration** — QR/PNG/Print، إعدادات، تسجيلات، إلغاء.
- تطبيق الموظف: **New Visitor Registration** — QR كبير، إرشادات بثلاث لغات، تحديث، اختيار فعالية، عدد المؤكد/المعلّق/المتاح.

### ملفات معدّلة
- `class-akf-db.php`, `class-akf-tickets-admin.php`, `class-akf-ticket-types.php`, `class-akf-events.php`
- `akf-mobile/lib/features/events/registration_qr_screen.dart` (جديد), `models.dart`, `ticket_repository.dart`, `router.dart`, `dashboard_screen.dart`
- الوثائق: `SELF-REG-PLAN.md`, `SELF-REG-API.md`, هذا التقرير.

## 4) اختبارات لم تُنفّذ
- استلام بريد التحقق فعلياً من صندوق بريد حقيقي (استُخدم تسجيل مؤقت للرمز أثناء الاختبار، ثم أُزيل وحُذف ملفه).
- مسح QR من هاتف زائر حقيقي وفتح الصفحة في متصفحه.
- أجهزة iOS، تعطيل/انتهاء الرابط، تجاوز السعة، تسجيل فعالية B كامل حتى التذكرة.
- Code128 (التذاكر المعتمدة تطبع Code39).
