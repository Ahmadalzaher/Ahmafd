# Gate Staff User Guide (draft)

## Sign in
Open the app and enter your WordPress username and **Application Password**, not
your normal account password. Create one under WordPress → Users → Profile →
Application Passwords.

## Choose event and gate
On the dashboard, open **Events** and select the assigned event and your entrance.
Scanning is disabled until an event is selected.

## Scan
The camera starts automatically when you open the scanner (you may need to tap
Start camera the first time Android asks for permission). Point it at the ticket
QR or Code128 barcode. The screen shows `QR detected — checking with server …`
and then the authoritative result. A second scan of the same ticket shows
`ALREADY CHECKED IN`.

## Offline
If the server cannot be reached, the app shows a red connection warning and
disables scanning. No ticket can be admitted offline. Tap Retry; scanning resumes
only after a successful server health check.

## Supervisor
Supervisors can open **Supervisor**, enter the ticket token and a mandatory
reason, and reverse an accidental check-in. Every reversal is audited.

## Languages
Settings → Language: Deutsch, English, العربية (full RTL layout).

## Sound / vibration
Settings allows sound and vibration to be switched off. Visual result screens
always remain authoritative.
