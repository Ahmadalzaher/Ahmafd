إضافة مخصصة لموقع Arab Kulturfestival تجمع بين النشرة البريدية وتسجيل الحضور في الفعاليات، بإدارة كاملة من لوحة ووردبريس وبالثلاث لغات (الألمانية، الإنجليزية، العربية).

== الوصف ==
Yalla Engage إضافة ذاتية مدیریت لا تعتمد على إضافات خارجية للنشرة البريدية. توفر:
1. نشرة بريدية كاملة: اشتراك، تأكيد مزدوج (Double Opt-in)، كتابة وإرسال الحملات، إلغاء اشتراك.
2. تسجيل الحضور في الفعاليات مع تأكيد بالبريد الإلكتروني.
3. لوحة إدارة واحدة: المشتركون، النشرات، التسجيلات، الإعدادات، فحص البريد، مساعدة.
4. جداول قاعدة بيانات مخصصة (لا تعتمد على أنواع المشاركات المخصصة CPT).
5. توافق مع كاش WP Rocket عبر تحديث nonce بأجاكس.
6. أدوات تصدير ومحو البيانات الشخصية (DSGVO).

== التركيب ==
1. ارفع مجلد yalla-engage إلى wp-content/plugins/ عبر FTP أو File Manager في Hostinger.
2. فعّل الإضافة من صفحة الإضافات في لوحة ووردبريس.
3. عند التفعيل، تُنشأ جداول قاعدة البيانات تلقائياً.
4. أضف shortcode [yen_newsletter] في الفوتر أو أي صفحة لعرض نموذج الاشتراك.
5. نموذج التسجيل يظهر تلقائياً أسفل صفحات فعاليات yd_event ما لم تستخدم shortcode [yen_registration].

== الإعدادات ==
اذهب إلى "النشرة والتسجيل" → "الإعدادات" وضبط:
- بريد الإشعار للمسؤول عند تسجيل جديد.
- حجم الدفعة لإرسال الحملات (افتراضي: 20 كل 5 دقائق).
- نصوص رسائل البريد والنماذج بالألمانية والإنجليزية والعربية (قابلة للتعديل).

== Cron Job في Hostinger ==
WP-Cron يعتمد على زيارات الموقع. إذا كانت الزيارات قليلة، أضف مهمة Cron حقيقية في Hostinger hPanel:
- الأمر: wget -q -O - "https://arab-kulturfestival.de/wp-cron.php?doing_wp_cron=1" >/dev/null 2>&1
- التكرار: كل 5 دقائق.

== إزالة الإضافة ==
عند حذف الإضافة من لوحة الإضافات، يُسأل إن كنت ترغب في حذف البيانات نهائياً (الافتراضي: لا تُحذف).

== اللغات ==
الألمانية (الافتراضية)، الإنجليزية، العربية (RTL). جميع النصوص قابلة للتعديل من صفحة الإعدادات.

== متطلبات ==
- PHP 8.0 أو أحدث.
- ووردبريس 6.0 أو أحدث.
- wp_mail() يعمل (يمكنك ضبط SMTP عبر إضافة WP Mail SMTP).
